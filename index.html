ゲーム概要

Rampart (ランパート)は、トランプ1組で遊ぶ2人用の対戦カードゲームです。 プレイヤーはカードで防御壁を構築しながら、相手の壁を攻め崩し、ライフカードを全て裏返すことで完全勝利を目指します。

壁の数字・スート(絵柄)・段の配置が戦略の鍵。作戦カード(J/Q/K)や地形カードを駆使して相手の一手先を読む、思考型のカードゲームです。

共通ルール:カードの数字を使う場面では、A=1、J=11、Q=12、K=13として扱います。
サマリーシートは こちら からダウンロードできます。

ゲームの準備

手順
  1. ジョーカーが混ざっていないか確認し、あれば除外します。
  2. Aを4枚抜き出し、各プレイヤーに2枚ずつ配る。表向きにしてライフゾーンに並べます。
    ← 各プレイヤーのライフ(初期値2)
  3. 5を4枚・7を4枚を抜き出し、一方に5を4枚、他方に7を4枚渡します。 各プレイヤーは4枚の中からスートを2つ選び地形カードとして獲得します。残りは山に戻します。
    または7のセット
  4. 地形カードを3×3グリッドの下(1列に1枚まで)にセットします。
    後から手札に加わった5や7は地形カードとしては使えません。
  5. 残り44枚をシャッフルし、各プレイヤーに6枚ずつ配ります。 残りは資源の山として中央に置きます。
  6. じゃんけんなどで先行・後攻を決め、先行からプレイを始めます。

地形カード

地形カードはグリッドの各列の下に配置し、条件が揃ったとき任意で発動できる特殊効果を持ちます。発動しないことも選べます。

♠ スペード

発動条件:この列への攻撃が宣言されたとき

効果:攻撃力を半分(端数切り捨て)にする。割り切り攻撃も無効化。

発動後、このカードは瓦礫の山へ。

♦ ダイヤ

発動条件:この列の壁が全て崩されたとき

効果:山札から2枚を手札に加える(6枚超でもOK)。山札がなくてもゲームは終了しない。

発動後、このカードは瓦礫の山へ。

♣ クラブ

発動条件:この列に3段が揃い、1段目が表向き・縦向きになったとき

効果:スートに関わらずこの列を強固な壁として扱う。

強固な壁が解除されたら瓦礫の山へ。

♥ ハート

発動条件:この列の壁が全て崩され、かつ自分のライフが1つ以上失われているとき

効果:このカードをライフゾーンに表向きで追加。最大ライフが3になる。

ライフとして残り続ける。

構築・攻撃フェーズで条件が揃った場合に発動できます。発動はあくまで任意です。

ゲームの進行

各プレイヤーは自分のターンに、以下の4つのフェーズを順番に行います。先行の1ターン目は攻撃フェーズをスキップします。

作戦フェーズ任意

手札のJ・Q・Kを1枚まで選び作戦カードとして使えます。ライフゾーンの隣に置き、即座に効果を発動します。

カードスート効果
♠ スペード このターンの全攻撃の攻撃力を2倍にする。
♦ ダイヤ 瓦礫の山から好きなカードを1枚手札に加える。加えたカードは相手に見せない。手札6枚超でもOK。
♣ クラブ 相手の1段目の壁を1枚選び横向きにする。強固な壁の構築を阻止できる。
♥ ハート ライフを1つ回復(裏向きのAを1枚表向きに戻す)。満タン時は枚数増加なし。
追加コスト:作戦カードと同じスートのカードを手札から1枚支払うことで、構築フェーズ(+1枚配置)か攻撃フェーズ(+1回攻撃)のどちらかを強化できます。
  • 構築を強化 → 追加コストカードを横向きに作戦カードの隣に置く
  • 攻撃を強化 → 追加コストカードを縦向きに作戦カードの隣に置く

構築フェーズ任意

3 × 3グリッドに手札から最大2枚(構築の追加コストあれば3枚)配置して防御壁を作ります。

配置のルール
  • 各列は1段目 → 2段目 → 3段目の順にしか積めない。
  • 上の段は下の段より必ず小さい数字(同じ数字も不可)。
  • 1回のターンで異なる列に分けて配置できる。
  • 1段目のカードは裏向きに配置できる(ブラフ)。
    ※攻撃を受けるまで表にできない。
強固な壁
  • 3段が全て同じスートで揃うと強固な壁になる。
  • 1段目が裏向きまたは横向きの場合は強固な壁にならない。
  • 強固な壁がある間は新しい壁を構築できない。解除されれば再び構築可能。

攻撃フェーズ任意

基本は1ターン1回の攻撃。攻撃の追加コストを支払っていれば2回攻撃できます。1回の攻撃で手札から1〜2枚を出し、数字の合計が攻撃力になります。スペード作戦の2倍効果がある場合は合計後の値を2倍にします。

攻撃力の計算例
+ = 16 (スペード作戦あり → 16 × 2 = 32)
先行の1ターン目は攻撃フェーズをスキップします。
攻撃には細かいルールがあります。

整理フェーズ

  1. 使用した作戦カード・追加コストカードを瓦礫の山へ移動する。
  2. 手札が6枚になるように資源の山から補充する(すでに6枚以上なら補充しない)。
  3. 資源の山が尽きて6枚に補充できない場合、ゲーム終了 → 勝利判定へ。

攻撃の詳細ルール

壁への攻撃

相手に壁がある場合、壁から1枚を選んで攻撃します。選んだカードの数字が防御力です。

状況結果
攻撃力 > 防御力壁を破壊。破壊された壁の上にあるカードも全て破壊する。
攻撃力 = 防御力攻撃失敗。
攻撃力で防御力が割り切れる
(攻撃力 < 防御力)		壁を破壊(スライドあり)。貫通判定へ。
それ以外攻撃失敗。
割り切り攻撃の例
で を攻撃

3 < 9 だが、9 ÷ 3 = 3 (割り切れる) → 壁を破壊してスライド処理。

壁がない場合(直接攻撃)

攻撃力に関わらず相手のライフカードを1枚裏返します。全ライフが裏返ったら勝利判定へ移行します。

強固な壁への攻撃

攻撃が成功しても即座には破壊されません。

攻撃した段に関わらず、1段目のカードを横向きにする。
→ これにより強固な壁の状態が解除される。
裏向きカードへの攻撃

裏向きカードを攻撃した場合、まず表向きにします。

  • 表にしたことで列にスートが揃った
    → その時点で強固な壁になる。
  • 表にしたカードが ♣クラブ だった
    → トラップが発動し、攻撃失敗。攻撃に使ったカードは瓦礫の山へ。

欠陥工事

相手の壁がルール違反の配置になっていることに気づいた場合、その列を破壊できます。

違反の定義:上の段が下の段と同じ数字、または大きい数字になっている場合。
指摘できるタイミング
  • 自分のターンの作戦フェーズ開始前
  • 相手の壁カードが表向きになったタイミング

指摘できる列は1列のみです。破壊されたカードは瓦礫の山へ移動します。

勝利判定

完全勝利:相手のライフカードを全て裏返したプレイヤーの勝ちです。

資源の山が尽きてゲームが終了した場合は、以下の順に勝者を決めます。

1
ライフが多い方が勝ち。(表向きのライフカードの枚数)
2
壁カードの枚数が多い方が勝ち。
3
地形カードの枚数が多い方が勝ち。
4
壁カードの数字の合計が"小さい方"が勝ち。
全て同じなら引き分け。
